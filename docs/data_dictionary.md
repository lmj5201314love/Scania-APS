# Scania APS 数据字典说明

Scania APS 数据集中的特征已经匿名化，除标签列 `class` 外，项目无法获得每个字段对应的真实传感器、零部件或物理含义。

## 字段结构

- `class`：目标标签。
  - `pos` 表示 APS 系统相关故障样本。
  - `neg` 表示非 APS 系统相关故障样本。
- 其余字段：匿名数值特征，例如 `aa_000`、`ab_000`、`ac_000` 等。
- 原始 CSV 中的 `"na"` 表示缺失值，读取时应转换为真正的缺失值。

## 使用原则

1. 不对匿名字段虚构业务含义。
2. 字段解释以数据分布、缺失率、模型表现和成本结果为依据。
3. 高缺失字段不直接等同于无用字段，需要通过消融实验验证。
4. 面试或报告中可以说明“特征匿名限制了物理层面的可解释性”，这是项目局限之一。

后续如果补充特征分布分析或模型解释，可在本文件中维护字段级别的统计摘要。
