# Triage labels

本文件记录工程技能使用的五类 triage 状态，以及它们在本项目 GitHub Issues 中对应的标签名。

| 技能中的角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者判断和分流 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可以交给 agent 独立执行 |
| `ready-for-human` | `ready-for-human` | 需要人类实现、判断或介入 |
| `wontfix` | `wontfix` | 不会继续处理 |

当技能提到某个 triage 角色时，使用上表右侧对应的标签字符串。

如果未来 GitHub 仓库中采用了新的标签命名，直接更新本文件右侧“本项目标签”列。
